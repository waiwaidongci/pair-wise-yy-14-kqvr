# hxyfront-62013 木构榫卯测绘复核台

源提示词编号：8

古建筑木结构榫卯构件测绘复核前端：按 **建筑 → 轴线 → 构件编号** 建档，录入木材、榫型、截面、朝向、含水率与病害范围，并围绕硬性复核规则驱动关系边、修缮任务与统计。

## 功能与规则

- **建档录入**：建筑、轴线、构件编号、构件名称、木材种类、榫卯类型、截面宽高、朝向、含水率、病害部位/范围/是否贯穿截面、修缮建议、录入人。
- **待复核硬规则**（命中任一即只能进入待复核，不生成关系边、不生成修缮任务）：
  1. 同一建筑下「轴线 + 构件编号」重复；
  2. 截面尺寸非正；
  3. 含水率 > 18%；
  4. 损伤贯穿截面。
- **换人复核**：复核人不得与录入人为同一人，须现场填写实测截面、实测含水率、实测贯穿判定；实测值仍不达标不予通过；通过后实测值写回构件并立即重算。
- **节点复核**：关系节点两端 **榫型 / 截面 / 朝向** 任一不符即冻结节点，关联构件的下游修缮任务同步冻结；节点进入冻结时自动保存两端旧版快照留档。待复核构件参与的节点为「挂起」状态。
- **即时重算**：节点、修缮任务、统计均为派生状态，上游构件一改，清单、关系图、待办与统计立即一致更新；数据持久化到浏览器，刷新后状态不变。
- **视图**：复核总览、构件清单（建筑/榫型/状态/关键词筛选）、尺寸记录表（含 CSV 导出）、病害标记图、单栋建筑构件关系图（按轴线分列 + 一致性清单 + 建边预览）、待复核队列、修缮待办、旧版留档（构件版本 + 冻结快照）。

## 技术栈

React 19 + Vite + TypeScript，无额外运行时依赖；状态用 React Context + 全量派生（`src/domain.ts`），localStorage 持久化。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62013

生产构建：

```bash
npm run build && npm run preview
```

## 代码结构

- `src/domain.ts` — 硬性校验、节点复核、任务与统计派生（纯函数）
- `src/store.tsx` — 全局状态、复核/建边/留档操作、持久化、示例数据
- `src/views/` — 八个业务视图
- `src/components/` — 表单、徽章、弹窗等公共组件
